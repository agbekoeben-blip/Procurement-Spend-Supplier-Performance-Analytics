# Dataset Information

This project uses a synthetic procurement dataset for portfolio and analytical practice purposes.

The dataset represents procurement activities across multiple organizational departments, suppliers, products, contracts, purchase orders, purchase order line items, invoices, and budgets.

## Tables

The dataset contains the following eight tables:

- Suppliers
- Departments
- Products
- Contracts
- PurchaseOrders
- PurchaseOrderItems
- Invoices
- Budgets

The procurement transactions cover the period **2022–2025**, including **10,000 purchase orders**.

## Disclaimer

This dataset is synthetic and does not represent the procurement records, suppliers, contracts, spending, or performance of any real organization.

All findings and recommendations in this project are provided for educational and portfolio demonstration purposes.
